# Project Report

## Problem Statement

Enterprise product teams need a unified system to analyze telemetry, support tickets, application logs, internal documents, ML predictions, and GenAI-generated answers. InsightOps AI solves this by combining data pipelines, ML models, product analytics, and Agentic RAG into one platform.

## Key Outcomes

- Built synthetic telemetry pipeline for enterprise product events.
- Created KPI tables for conversion, failure rate, latency, and product-area trends.
- Trained ML models for ticket severity and churn risk.
- Implemented log anomaly detection for incident triage.
- Built a citation-based RAG assistant over markdown knowledge-base documents.
- Added agent routing for analytics, logs, and RAG questions.
- Added FastAPI, Streamlit, Docker, Airflow, MLflow, and GitHub Actions.
